Bordered Content Blocks 1.0 · Help

Quick help

Free content blocks for Confluence Cloud: panels, cards, metadata, steps and a page-level Panel Migrator.

Your first panel

  1. In a page, type /Bordered and choose Bordered panel (live edit) if the frame must stay visible while typing, or Bordered panel for Confluence's native rich-text body.
  2. Open the macro pencil, choose a tone and add a title/icon.
  3. Save the macro, then update the page.

Live docs: the native-body panel hides its frame while Confluence edits the body. Leave the body editor to see it again; use the live edit panel when the frame must stay visible.

Other blocks

  • Bordered card: icon, title, short description and one link; max width 460px.
  • Bordered metadata: owner, status, target date and other scannable facts.
  • Bordered steps: rollout plans, runbooks and onboarding sequences.

Migrate existing panels

Open Apps → Panel migrator, paste a page URL or ID, scan (read-only), review the native panels, then convert. Empty panels are skipped; conversion creates a page version and View page history lets you roll back.

Known limits

  • Bordered synced callout is not included in 1.0.
  • The native-body panel does not add a native-style full-width control; use live edit or a full-width layout when full width is required.
  • PDF/Word exports approximate the panel border with a table.
