Quick start

Page Pulse is one macro with three modes. Everything is configured from the macro dialog; there is no separate admin setup.

Insert a pulse

  1. Open a Confluence page in edit mode.
  2. Type /Page Pulse and choose the macro.
  3. Pick Poll, Rating or RSVP.
  4. Write the question or prompt, fill in the options, and choose when results should be visible.
  5. Save the macro, then publish the page.

Poll

Add two to ten options. A poll can be single-choice or multi-select, and can close on a date. Results can be visible always, only after a person votes, or only after the poll closes.

Rating

People choose one to five stars. The macro shows the average and the distribution across the five values. A rating has no options to configure.

RSVP

People choose Going, Maybe or Can't go. Set an optional capacity to limit the number of “Going” responses; when the event is full, new “Going” responses are declined and the remaining choices stay available.

Results and visibility

  • Always — results are visible as soon as the page is published.
  • After a person votes — each person sees results after their own response.
  • After the pulse closes — results stay hidden until the close date.
  • Voter names can be hidden from results and CSV.

Change or remove a response

One response is allowed per person per pulse. A person can change their choice or remove their response from the macro at any time. Removing a response decrements the totals immediately.

Download CSV

When results are visible to you, choose Download CSV to get the question, options, counts and response timestamps. The file is named after the page ID, for example page-pulse-8716289.csv.

Byline count

Page Pulse adds an item to the page byline showing the total number of responses collected on that page across all pulses. The count refreshes when the page is reloaded.

Permissions and data

  • Responses follow the page's Confluence permissions. A person who cannot read the page cannot respond.
  • The app stores the Atlassian account ID, the selected choice and a timestamp in Forge KVS. Display names are read from Confluence at view time and are not stored.
  • The app does not send data to an external server, use runtime AI, or collect analytics or advertising identifiers.

Known limitations (v0.1)

  • Two pulses with the same question and options on the same page share one result set. Change the question to separate them.
  • Close dates are interpreted as the end of the day in UTC.
  • Up to 10 voter names are shown inline and included in the CSV; larger polls show counts and “+N more”.
  • RSVP capacity is checked before the write, not in a transaction; two simultaneous “Going” responses can overshoot by one.
  • There is no “delete all results” action; responses are removed per person.
  • Live docs and blog posts are not verified; the macro is designed for pages.

Troubleshooting

The macro shows a loading message

Reload the page. If it persists, check that the app is installed for the site and that you can read the page.

My vote did not appear

Reload the page and try again. If the page is restricted, ask the page owner for access. If the problem continues, contact support with the site URL, page ID and the time of the attempt.

The byline count looks stale

The byline refreshes with the page. Reload after new responses to see the latest total.
