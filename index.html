Bordered Content Blocks

Consistent callouts, cards, metadata and steps — plus a one-click path from existing native panels.

What it does

Replace inconsistent native panels with one tone system. Keep Confluence's native rich-text body for lists, tables and mentions, or use the live edit panel when the frame must stay visible while typing.

Panel Migrator scans a page, lists native panels, and converts them while keeping the body and creating a normal page version.
